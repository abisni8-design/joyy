WEBGIS PERTANIAN PRESISI - DESA SERITI

INSTALASI:
1. Ekstrak folder webgis ke C:\xampp\htdocs\webgis
2. Jalankan Apache dan MySQL di XAMPP.
3. phpMyAdmin -> import database/webgis.sql. Database yang dipakai aplikasi: webgis_pertanian.
4. Setelah database selesai dibuat, import database/sawah_86_seed.sql untuk memasukkan 86 petak sawah.
5. Buka http://localhost/webgis/
6. Peta: http://localhost/webgis/user/peta.php
